# Competitive Programming Code Library

A personal collection of algorithms, data structures templates for competitive programming. The implementations are written in C++ and are intended to be copied and adapted during contests (or just look up implementation for algorithms review).

## Contents 

| Directory | Topics |
| --- | --- |
| [`basic`](basic/) | Common techniques and foundational algorithms |
| [`dp`](dp/) | Dynamic programming optimizations and patterns |
| [`ds`](ds/) | Data structures, including trees and range-query structures |
| [`flows`](flows/) | Network flow algorithms |
| [`game`](game/) | Combinatorial game theory |
| [`geo`](geo/) | Computational geometry |
| [`graph`](graph/) | Graph algorithms, connectivity, paths, and trees |
| [`math`](math/) | Algebra, transforms, polynomials, and other mathematical tools |
| [`misc`](misc/) | General techniques and contest utilities |
| [`numeric`](numeric/) | Number theory and numerical algorithms |
| [`strings`](strings/) | String matching, hashing, automata, and suffix structures |
| [`template`](template/) | Starting templates and debugging helpers |

File names describe the algorithm or technique they implement, so repository search is usually the quickest way to find a specific snippet.

## Conventions

- Implementations generally use **1-indexing** and **inclusive ranges**.
- Files that use 0-indexing or exclusive ranges document that choice in comments.
- Many snippets are designed as references rather than standalone programs. Check their constants, types, indexing, global state, and expected input format before use.
- Complexity notes and usage examples vary by file; read the implementation carefully and test it against the constraints of your problem.

## Using the Library

1. Find the relevant topic directory or search by algorithm name.
2. Copy the implementation into your solution.
3. Adapt constants, types, interfaces, and indexing to the problem.
4. Test the adapted code on small cases and boundary conditions before submitting.

The starter files in [`template`](template/) provide a minimal contest setup and debugging utilities.
